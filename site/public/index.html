Type what you are importing in plain English and get back every duty, levy and condition that applies — each line linked to the exact page of the official PDF it was read from. The arithmetic is ordinary code, not a language model, so the same question always gives the same answer.

And when it cannot be sure

Ask it about rice and it stops. The tariff gives a two-part rate — 75%, or a fixed amount per tonne, whichever is higher — and settling that needs the quantity. So the total reads needs officer and the breakdown shows only what is known. A blank an officer fills in is recoverable. A plausible wrong rate is not.

It runs entirely on your machine. The tariff and the source PDFs are inside the app, and nothing you type leaves it.

Windows will warn you. Here is why.

These builds are not code-signed — a certificate costs a few hundred dollars a year and this is a free tool. Windows does not recognise the publisher, so SmartScreen shows a blue box the first time you run the installer. The file is the one GitHub built from the source, and you can check its SHA-256 against the release.

  1. Run the downloaded Customs Compliance-Setup file.
  2. On the blue “Windows protected your PC” screen, click More info. It is a small link, easy to miss.
  3. Click Run anyway.
  4. Choose where to install it. That is the last question — the app carries its own database and needs nothing else installed.
On macOS
Right-click the app and choose Open the first time instead of double-clicking. Gatekeeper allows it that way.

What you get

  • Ask in words, or fill in the form “a laptop worth 150,000 for my company”, a bare HS code like 2523.29.00, or a pasted paragraph — all of them reach the same lookup.
  • Search the law Paste a passage to find where it appears across every loaded document, with each hit opening the source PDF at the right page.
  • Answers in plain English Every result opens with a sentence anyone can read, before the table that shows the working behind it.
  • It flags rather than guesses Sensitive items, two-part rates and superseded sources are marked, and no total is shown that rests on one of them.

Add your own documents

Drop in a folder of PDFs — a hundred at a time — and the app reads them where it stands. Scanned documents are recognised automatically. Nothing has to be installed alongside it, and it never goes online to do the work.

Everything you add becomes searchable and page-linked straight away. Where a document is a rate schedule, the app proposes the rows it found and puts them in a review queue with the source passage beside each one. Nothing reaches an assessment until a person approves it. Reading a table is a job for software; deciding what the law says is not.

Roughly how long
A PDF with a text layer takes seconds. A scan has to be read a page at a time — budget two to four seconds a page, so about fifteen minutes for a 300-page Act. It runs in the background.

Keeping it current

On Windows and the Linux AppImage the app checks for a new version shortly after it starts and then every few hours, downloads it in the background, and offers to restart. You can force a check from Help → Check for updates. Your database, the documents you added and your logged searches all survive an update.

macOS is the exception. Apple requires an update to be signed by a registered developer before it will install one, and these builds are not signed — so the Mac app tells you when a new version exists and sends you back here to fetch it.

Installed from a .deb?
That copy belongs to your package manager. Install the newer .deb, or switch to the AppImage if you would rather it updated itself.
